# Desafio 03 — Integrando Dados com MySQL Azure e Transformando com Power BI

## Descrição do desafio

O desafio proposto pela formação Power BI Analyst da DIO tem como objetivo integrar um banco de dados MySQL hospedado no Microsoft Azure ao Power BI, realizando posteriormente processos de limpeza, transformação e preparação dos dados.

## Considerações sobre a execução

Após analisar os requisitos técnicos e a infraestrutura necessária, optei por não executar este projeto neste momento.

A atividade exige a utilização de uma instância MySQL no Microsoft Azure, serviço que pode envolver custos de infraestrutura e manutenção.

Como já possuo experiência prática com bancos de dados MySQL e MariaDB, e a contratação de serviços Azure não faz parte das minhas prioridades profissionais atuais, decidi não ativar uma assinatura exclusivamente para este exercício.

## Conhecimentos abordados

Durante o estudo dos materiais disponibilizados na formação, foram revisados conceitos relacionados a:

- Conexão com diferentes fontes de dados.
- Estrutura e relacionamentos de bancos de dados relacionais.
- Integração de dados com Power BI.
- Limpeza e transformação de dados.
- Tratamento de valores nulos e inconsistências.
- Mesclagem de consultas e preparação de dados para análise.

## Status do projeto

**Não implementado.**

A decisão foi tomada considerando a infraestrutura necessária e a priorização dos próximos projetos da formação.

Os conhecimentos apresentados neste módulo permanecem como referência para aplicações futuras.
