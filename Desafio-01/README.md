# Desafio 01 — Dashboard Financeiro com Power BI

Primeiro desafio prático da formação Power BI Analyst da DIO.

## Sobre o projeto

Dashboard desenvolvido no Power BI Online, utilizando dados financeiros de exemplo para apresentar indicadores de vendas e análises por produto, país e período.

## Funcionalidades

- Indicador de total de vendas.
- Gráfico de vendas por produto.
- Análise de vendas por data.
- Comparação de vendas por país.
- Segmentação de dados por ano.
