# Desafio 02 — Relatório de Vendas com Power BI

Segundo desafio prático da formação Power BI Analyst da DIO.

Relatório desenvolvido no Power BI Online, contendo indicadores financeiros, análise mensal de vendas, gráficos por segmento e produto, segmentação por datas e botões interativos para alternar visualizações.

**Observação:** o mapa foi configurado, mas sua exibição ficou indisponível devido às permissões do ambiente Power BI Online.
